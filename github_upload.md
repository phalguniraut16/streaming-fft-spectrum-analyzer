# Upload to GitHub

1. Download and extract `streaming_fft_spectrum_analyzer.zip`.
2. Open the repository on GitHub and choose **Add file → Upload files**.
3. Upload the contents of this folder (including `rtl/`, `tb/`, `scripts/`, and `docs/`).
4. Commit with a message such as `Add streaming FFT spectrum analyzer RTL prototype`.
5. Before listing this as a completed FFT implementation on a CV, finish the canonical SDF twiddle schedule and numerical validation described in `architecture.md`.
